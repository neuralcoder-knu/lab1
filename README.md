# Лабораторна робота № 1 — RDF та SPARQL

Граф знань про відеоігри, студії-розробники та платформи.

Дисципліна «Принципи, методи зв'язування даних у застосуваннях Семантичної павутини»,
магістратура ФІТ КНУ, спеціальність F2.

## Предметна область

П'ятнадцять ігор семи студій із п'яти країн. Дані зібрано вручну з відкритих джерел
(офіційні сторінки студій, Вікіпедія) і зафіксовано у `catalog.py`.

Область обрано так, щоб сутності перетиналися: одна студія випускає кілька ігор,
один видавець працює з кількома студіями, одна платформа обслуговує більшість ігор.
Це дає зв'язний граф, на якому запити з переходом через кілька зв'язків мають
змістовні відповіді.

## Структура графа

Сім типів сутностей: `Game`, `Studio`, `Publisher`, `Platform`, `Genre`, `Person`, `Country`.

Сім типів зв'язків плюс дві літеральні властивості:

| Властивість | Від | До |
|---|---|---|
| `developedBy` | Game | Studio |
| `publishedBy` | Game | Publisher |
| `releasedOn` | Game | Platform |
| `hasGenre` | Game | Genre |
| `foundedBy` | Studio | Person |
| `basedIn` | Studio | Country |
| `sequelOf` | Game | Game |
| `releaseYear` | Game | xsd:integer |
| `foundingYear` | Studio | xsd:integer |

Показники: 398 трійок, 68 екземплярів сутностей.

## Повторно використані словники

Schema.org (`VideoGame`, `Organization`, `Person`, `Country`, `name`, `datePublished`,
`gamePlatform`), Dublin Core Terms (`title`), FOAF (`name`), OWL (`sameAs`),
RDFS (`Class`, `subClassOf`, `label`, `domain`, `range`).

Власні класи оголошено підкласами відповідних класів Schema.org, тому граф
залишається сумісним із зовнішніми інструментами.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Створює `games.ttl`, `games.jsonld`, `games_linked.ttl`, `graph_full.png`,
`graph_core.png`, `graph.html`.

## Технічні рішення

**URI латиницею, підписи українською.** Назви транслітеруються класом `Slugger`,
а людські підписи зберігаються окремо через `rdfs:label` і `schema:name` з міткою
мови `@uk`. Кирилиця в URI дала б відсоткове кодування й нечитабельний Turtle.

**Рік як `xsd:integer`, не `xsd:gYear`.** Літерали `gYear` не підтримують порівняння
в rdflib: фільтр мовчки повертає нуль рядків. Для сумісності зі Schema.org рік
додатково записано як `schema:datePublished` з типом `gYear`, але у фільтрах
використовується цілочисельна властивість.

**Зведення однойменних організацій.** Valve, Larian Studios і 11 bit studios
виступають водночас студіями та видавцями, тому отримують окремі URI за роллю,
між якими проставлено `owl:sameAs`. Це задача ототожнення сутностей у межах
одного графа.

**Пошук у Wikidata за назвою.** Ідентифікатори не зашиті в код: клас `WikidataLinker`
шукає ресурс за англійською міткою з перевіркою класу через `wdt:P31/wdt:P279*`.
Якщо SPARQL-сервіс недоступний (наприклад, HTTP 429), клас переходить на Wikidata
Action API, де клас перевіряється лише прямо через `P31`, і повідомляє про це у виводі.
